Google Sheets 연동 설정 방법

이 HTML은 Google Sheets에서 데이터를 자동으로 불러옵니다.
시트 내용이 바뀌면 ↻ 새로고침 버튼을 누르거나 페이지를 새로고침하면 최신 데이터가 반영됩니다.

1
시트를 웹에 게시하기

Google Sheets 열기 → 파일 → 공유 및 내보내기 → 웹에 게시
게시할 시트: 📋 전체 데이터 선택 → 형식: 쉼표로 구분된 값(.csv) → 게시 클릭

2
게시 URL 복사

게시 후 나오는 URL을 복사하세요. 형태는 아래와 같습니다:

https://docs.google.com/spreadsheets/d/[ID]/pub?gid=[GID]&single=true&output=csv
3
HTML 파일 상단 URL 수정

이 HTML 파일을 텍스트 편집기로 열고, 아래 줄을 찾아 복사한 URL로 교체하세요:

const SHEETS_CSV_URL = '여기에 게시 URL 붙여넣기';
4
GitHub Pages에 올리기 (팀 공유)

HTML 파일을 index.html로 이름 변경 → GitHub 새 저장소에 업로드 →
Settings → Pages → main branch로 배포 → 팀원에게 URL 공유

https://[계정명].github.io/[저장소명]/

팀 업무 흐름

📝 캠페인 종료 → 담당 AE가 Google Sheets에 행 추가 → 이 페이지에서 새로고침 → 제안서 전 단가 검색·활용
현재 연결된 시트 URL
